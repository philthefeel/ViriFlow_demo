Event counts

Explore imported samples and compare event totals across experimental groups.

Filters and grouping

Each filter uses exact values. All values are selected initially. Cmd/Ctrl-click for multiple values; selecting none returns no samples.

Custom sample labels

One line per sample: file_id[TAB]label. Example: FCS_00047[TAB]TON004 day16 replicate2. Paste two columns from Excel. Original IDs are preserved.

Donut sectors represent event totals; means use bar plots. Percentages describe shares of imported events among the filtered samples, before Top/Bottom selection. They are not frequencies relative to the original parent population. Group totals depend on the number of samples and acquired events; means do not establish biological abundance.
